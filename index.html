02 · HARDWARE

Partes del robot VEX IQ 2ª generación

El kit educativo VEX IQ (2ª gen.) incluye más de 1,000 piezas de construcción y toda la electrónica necesaria para energizar, controlar y programar el robot.

Motores

El Smart Motor es el motor inteligente del sistema. El kit trae 4 unidades, y se conectan a cualquiera de los 12 puertos del Brain mediante un cable inteligente, que detecta el tipo de dispositivo automáticamente.

Fuente oficial: vexrobotics.com — Kit Contents

Sensores

Incluye Touch LED, Bumper Switch, Optical Sensor y Distance Sensor (2ª gen.), todos conectados al Brain con un cable inteligente para detectar toques, choques, luz o distancia.

Fuente oficial: vexrobotics.com — Kit Contents

Piezas estructurales

Más de 1,000 piezas plásticas: vigas, placas, ejes, engranajes y conectores que se arman sin herramientas, usando principalmente pines a presión y el Pin Tool incluido.

Fuente oficial: vexrobotics.com — Education Kit

Controlador

El IQ Controller (2ª gen.) tiene dos joysticks analógicos, diez botones y radio Bluetooth 5.0 para manejar el robot y descargar programas de forma inalámbrica.

Fuente oficial: vexrobotics.com — IQ Controller

IQ Brain

El "cerebro" del robot: pantalla a color, 12 Smart Ports, Bluetooth 5.0, giroscopio de 6 ejes y ranura microSD. Ejecuta programas hechos en bloques, C++ o Python.

Fuente oficial: vexrobotics.com — IQ Brain

Batería

Batería de iones de litio de 7.2V, 2,000 mAh, con carga por USB-C (~2 horas) y luces indicadoras integradas para revisar su nivel.

Fuente oficial: vexrobotics.com — IQ Robot Battery

04 · CONEXIÓN

Emparejamiento inalámbrico

Cómo conectar por Bluetooth el IQ Brain (2ª gen.) con el IQ Controller (2ª gen.). Una vez emparejados, se reconectan solos cada vez que se encienden.

1

Prepara los equipos

Ten listos el Brain, la batería cargada y el Controller cargado.

2

Enciende el Brain

Inserta la batería y presiona el botón de Check (✔) para encenderlo.

3

Enciende el Controller

Presiona el botón de encendido central del Controller.

4

Verifica los LED

Ambos LED (Brain y Controller) deben verse en verde, indicando que están encendidos.

5

Entra a Settings

En la pantalla del Brain, usa las flechas para ir a Settings y presiona Check.

6

Selecciona Link

Dentro de Settings, elige la opción Link y presiona Check.

7

Confirma la conexión

Espera unos segundos: ambos LED parpadearán en verde cuando el emparejamiento sea exitoso.

Consejos: carga ambos dispositivos antes de emparejar, mantenlos encendidos durante todo el proceso, y si el ícono del Controller aparece en naranja en VEXcode IQ, revisa que el firmware esté actualizado.

Fuente oficial: VEX Library — Pairing a Controller (2nd gen) to Brain (2nd gen)

05 · ENERGÍA

Carga de la batería

Tanto la batería del robot como la del Controller se cargan por separado mediante un cable USB-C, en aproximadamente 2 horas cada una.

Batería del robot

1. Conecta el cable USB-C al puerto de carga.
2. Conecta el otro extremo a una fuente de energía.
3. Las luces indicadoras parpadearán mientras carga.
4. Espera a que dejen de parpadear.

Fuente oficial: VEX Library — Charging the Battery

Batería del Controller

1. Conecta el cable USB-C al puerto de carga del Controller.
2. Conecta el otro extremo a una fuente de energía.
3. Espera a que el indicador muestre carga completa.

Fuente oficial: VEX Library — Charging the Controller

Seguridad y cuidado: usa siempre un cable y adaptador en buen estado; la batería de 2ª gen. no funciona con el cargador antiguo de 1ª gen. (no se daña, pero tampoco carga); no fuerces el conector USB-C; evita dejarla descargada por mucho tiempo y guárdala en un lugar seco a temperatura ambiente.

06 · HARDWARE

El IQ Controller (2ª generación)

El mando con el que se maneja el robot manualmente y se comunica de forma inalámbrica con el Brain.

Joysticks (ejes A–D)

Izquierdo: ejes A y B. Derecho: ejes C y D. Cada eje va de -100 a 100, con 0 al centro. Botones centrales L3 y R3.

Botones frontales

E Up / E Down bajo el joystick izquierdo; F Up / F Down bajo el derecho.

Botones traseros

L Up / L Down y R Up / R Down, tipo "hombros", en la parte trasera del Controller.

Puerto USB-C y LED

Carga la batería y permite descargar programas. El LED indica: verde fijo = encendido; verde parpadeante = emparejado.

Fuente oficial: vexrobotics.com — IQ Controller · VEX Library — Button and Joystick Names

07 · HARDWARE

El IQ Brain (2ª generación)

El componente central del robot: ejecuta los programas y controla todos los motores y sensores conectados.

Botones (flechas + Check)

Dos flechas para navegar el menú y un botón central de Check (✔) para confirmar o seleccionar.

Pantalla a color

Muestra el menú Home, programas guardados, Settings y paneles de diagnóstico en tiempo real.

12 Smart Ports

Aceptan motores o sensores indistintamente: el Brain detecta el tipo de dispositivo automáticamente.

Menús y microSD

Hasta 4 programas guardados, menú Settings con la opción Link para emparejar, y ranura microSD para datalogging.

Fuente oficial: vexrobotics.com — IQ Robot Brain (2nd gen)

08 · SOFTWARE

Instalación de VEXcode IQ

El software oficial para programar VEX IQ, disponible en bloques, C++ y Python (Brain 2ª gen.), en versión web y como app instalable.

Computadora (Windows / Mac)

Usa la versión web en codeIQ.vex.com desde Chrome sin instalar nada, o descarga la app de escritorio desde la página oficial.

Chromebook

VEX recomienda usar la versión web de VEXcode IQ en Google Chrome, ya que las apps de Chrome dejaron de tener soporte.

Tablet (iPad / Android / Fire)

Se instala como aplicación desde la tienda correspondiente: App Store, Google Play o Amazon Appstore.

Descargar / abrir VEXcode IQ Fuente oficial: vexrobotics.com/vexcode/install/iq

09 · PROGRAMACIÓN

Descarga de programas al Brain

Cómo pasar un proyecto de VEXcode IQ al robot, por cable USB o de forma inalámbrica con el Controller.

1

Prepara el programa

Arma tu proyecto en VEXcode IQ (bloques, C++ o Python) y guárdalo.

2

Conecta el Brain

Por cable: conecta el Brain a la computadora con USB-C. Inalámbrico: empareja el Controller con el Brain y conecta el Controller a la computadora por USB.

3

Verifica la conexión

El ícono del Brain (y del Controller) debe verse en verde en la barra de herramientas de VEXcode IQ.

4

Descarga el programa

Elige uno de los 4 espacios del Brain y presiona descargar; aparecerá una barra de progreso.

5

Ejecuta el programa

Selecciónalo en la pantalla del Brain y presiona Check, o inícialo directamente desde el Controller.
